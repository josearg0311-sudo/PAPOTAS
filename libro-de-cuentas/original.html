Conectar base de datos

Para sincronizar entre dispositivos, este libro usa jsonbin.io, un servicio gratuito de base de datos. Es un registro rápido, sin tarjeta.

① Crear tu base de datos (una sola vez, en tu primer dispositivo)
  1. Entra a jsonbin.io y crea una cuenta gratis (email y contraseña).
  2. Una vez dentro, ve a Account → API Keys.
  3. Copia el valor de X-MASTER-KEY y pégalo aquí abajo.
② Conectar otro dispositivo a la misma base

Pega aquí el código que copiaste al crear la base en tu primer dispositivo (menú «⋯» → «Respaldo y copia local» → «Ver código actual»).

Tu código de sincronización

Copia este código y pégalo en la app cuando la abras en tus otros dispositivos (⚙ Base de datos → pega el código → Conectar). Guárdalo también en tus notas por si acaso.

Respaldo y copia local

Estas opciones son un respaldo extra. Para sincronizar entre dispositivos usa «⚙ Base de datos» en el menú «⋯».

☁ Código de mi base de datos

Vuelve a ver el código de tu base de datos actual, para pegarlo en otro dispositivo.

📄 Archivo de respaldo

Descarga un archivo y ábrelo en el otro dispositivo (por WhatsApp, correo, Drive, AirDrop…).

🔤 Código de sincronización

Genera un código, cópialo y pégalo en el otro dispositivo. Ideal si no quieres manejar archivos.
