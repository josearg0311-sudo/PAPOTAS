Sincronizar entre dispositivos

Esto no va a funcionar desde un archivo suelto. Estás abriendo el programa con doble clic, y el navegador no le deja hablar con jsonbin.io. Sube los archivos a tu dirección https y hazlo desde ahí. Todo lo demás —anotar, Excel, PDF, respaldo— sí funciona así.

El libro guarda una copia en jsonbin.io, un servicio gratuito. Se configura una vez en un dispositivo y los demás se conectan con un código.

Paso 1 · Crear la base (solo la primera vez)
  1. Entra a jsonbin.io y crea una cuenta gratis.
  2. Dentro, ve a Account → API Keys.
  3. Copia el valor de X-MASTER-KEY y pégalo aquí abajo.
Paso 2 · Conectar otro dispositivo

En el dispositivo que ya está conectado, abre Opciones → Ver código de sincronización y pega aquí ese código.
